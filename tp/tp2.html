TP2 – Les classes de héros

1IPOO – Projet fil rouge « Les Chroniques d'Ardelune » · Mercredi 2 décembre

Contexte

Les duels d'entraînement ont fait leurs preuves : la guilde d'Ardelune accueille désormais des aventuriers de plusieurs classes. Les guerriers frappent plus fort quand ils sont blessés, les mages lancent des sorts et les paladins, mi-guerriers mi-prêtres, soignent leurs alliés.

Tous restent des héros : ils ont des PV, des potions et une arme. Plutôt que de tout réécrire, vous allez les faire hériter de la classe Hero du TP1. 🧙

Ce TP en bref
  • Objectifs : créer des classes filles, appeler le constructeur de la classe mère, utiliser protected, redéfinir une méthode et mettre en œuvre l'héritage multiple.
  • Vous continuez dans le même dépôt que le TP1. Chaque nouvelle classe a son .hpp et son .cpp.
  • Les programmes d'essai remplacent temporairement le contenu de main.cpp. Gardez une copie de votre duel du TP1 : il revient à l'étape 6.
  • Un commit et un push à chaque étape terminée.

1 Préparer la classe Hero

protected

Les classes filles auront besoin des attributs de Hero. Dans Hero.hpp :

  1. passez les cinq attributs de private à protected ;
  2. ajoutez une méthode publique void heal(int amount) qui rend amount PV sans dépasser maxHealth. Une valeur négative est ignorée ;
  3. dans drinkPotion(), remplacez le calcul des PV par un appel à heal(30) : le code n'est écrit qu'une fois.

      #include "Hero.hpp"

      int main() {
          Hero aria("Aria", 100, Weapon("Épée courte", 12));
          aria.takeDamage(50);
          aria.heal(20);
          aria.heal(-5);
          aria.display();
          aria.heal(100);
          aria.display();
          return 0;
      }
    
Aria – 70/100 PV – 3 potion(s) – Épée courte (12 dégâts)
Aria – 100/100 PV – 3 potion(s) – Épée courte (12 dégâts)
Aria quitte l'aventure.
Pour valider, assurez-vous que…
  • le programme d'essai affiche exactement les trois lignes attendues ;
  • les attributs sont protected : main ne peut toujours pas les modifier ;
  • vous avez fait un commit « Hero prêt pour l'héritage » et vous l'avez poussé.

2 Le guerrier

Héritage · constructeur de la mère · redéfinition

Créez la classe Warrior dans Warrior.hpp et Warrior.cpp. Un guerrier est un héros :

ÉlémentRôle
class Warrior : public Herole guerrier hérite de tout ce que sait faire un héros
Warrior(std::string newName, Weapon newWeapon)appelle le constructeur de Hero avec 130 PV maximum
void attack(Hero& target) constredéfinit l'attaque : elle appelle d'abord l'attaque de Hero, puis, si le guerrier a moins de la moitié de ses PV, inflige 5 dégâts de plus et affiche Brom entre en rage : 5 dégâts de plus !

      #include "Warrior.hpp"

      int main() {
          Warrior brom("Brom", Weapon("Hache de guerre", 15));
          Hero dummy("Mannequin", 200, Weapon());
          brom.display();
          brom.attack(dummy);
          brom.takeDamage(70);
          brom.attack(dummy);
          dummy.display();
          return 0;
      }
    
Brom – 130/130 PV – 3 potion(s) – Hache de guerre (15 dégâts)
Brom frappe Mannequin avec Hache de guerre : 15 dégâts.
Brom frappe Mannequin avec Hache de guerre : 15 dégâts.
Brom entre en rage : 5 dégâts de plus !
Mannequin – 165/200 PV – 3 potion(s) – Bâton de marche (5 dégâts)

Brom quitte l'aventure.
Indices
  • Le constructeur tient en une ligne : Warrior::Warrior(string newName, Weapon newWeapon) : Hero(newName, 130, newWeapon) {}.
  • Hero::attack(target); appelle la version de la classe mère sans recopier son code.
  • Le guerrier lit health et maxHealth directement : ils sont protected.
Pour valider, assurez-vous que…
  • le programme d'essai affiche exactement les sept lignes attendues ;
  • Warrior ne redéclare aucun attribut de Hero ;
  • vous avez fait un commit « Classe Warrior » et vous l'avez poussé.

3 La magie

Une classe « capacité »

Les mages et les paladins utilisent du mana, une énergie magique qui se dépense à chaque sort. Plutôt que d'écrire le mana deux fois, créez une classe Spellcaster (lanceur de sorts) dans Spellcaster.hpp et Spellcaster.cpp. Ce n'est pas un héros : c'est une capacité que d'autres classes pourront ajouter.

ÉlémentRôle
int mana et int maxMana protectedmana actuel et maximum
Spellcaster(int newMaxMana)maxMana est ramené entre 0 et 100, puis le mana commence au maximum
int getMana() constaccesseur
bool spendMana(int cost)retire cost du mana et renvoie true. Refuse et renvoie false si le coût est négatif ou supérieur au mana restant
void displayMana() constaffiche    Mana : 20/50 (trois espaces au début) puis passe à la ligne

      #include "Spellcaster.hpp"
      #include <iostream>
      using namespace std;

      int main() {
          Spellcaster magic(50);
          cout << magic.spendMana(30) << " ";
          cout << magic.spendMana(30) << " ";
          cout << magic.spendMana(-10) << endl;
          magic.displayMana();
          Spellcaster tooMuch(500);
          tooMuch.displayMana();
          return 0;
      }

4 Le mage

Héritage multiple · masquage

Un mage est un héros et un lanceur de sorts. Créez la classe Mage dans Mage.hpp et Mage.cpp :

ÉlémentRôle
class Mage : public Hero, public Spellcasterhéritage multiple
Mage(std::string newName, Weapon newWeapon)appelle les deux constructeurs mères : 80 PV maximum, 60 de mana
bool castFireball(Hero& target)dépense 20 de mana et inflige 25 dégâts à la cible : Aria lance une boule de feu sur Brom : 25 dégâts. Sans assez de mana, affiche Aria n'a plus assez de mana ! et renvoie false
void display() constaffiche le héros, puis la ligne de mana

      #include "Mage.hpp"

      int main() {
          Mage aria("Aria", Weapon("Bâton runique", 6));
          Hero dummy("Mannequin", 200, Weapon());
          aria.display();
          for (int i = 0; i < 4; i++) {
              aria.castFireball(dummy);
          }
          aria.attack(dummy);
          aria.display();
          dummy.display();
          return 0;
      }

5 Le paladin

Héritage multiple · chaîne d'héritage

Un paladin est un guerrier (il entre en rage) et un lanceur de sorts. Créez la classe Paladin dans Paladin.hpp et Paladin.cpp :

ÉlémentRôle
class Paladin : public Warrior, public Spellcasterhéritage multiple, dont une mère qui hérite elle-même de Hero
Paladin(std::string newName, Weapon newWeapon)appelle le constructeur de Warrior et celui de Spellcaster avec 40 de mana
bool bless(Hero& ally)dépense 15 de mana et rend 25 PV à l'allié : Elwin bénit Aria : 65 PV. (les PV de l'allié après le soin). Sans assez de mana : Elwin n'a plus assez de mana !
void display() constaffiche le héros, puis la ligne de mana

      #include "Paladin.hpp"

      int main() {
          Paladin elwin("Elwin", Weapon("Marteau sacré", 10));
          Hero aria("Aria", 100, Weapon("Épée courte", 12));
          aria.takeDamage(60);
          elwin.bless(aria);
          elwin.takeDamage(80);
          elwin.attack(aria);
          elwin.display();
          return 0;
      }
    
Elwin bénit Aria : 65 PV.
Elwin frappe Aria avec Marteau sacré : 10 dégâts.
Elwin entre en rage : 5 dégâts de plus !
Elwin – 50/130 PV – 3 potion(s) – Marteau sacré (10 dégâts)
   Mana : 25/40
Aria quitte l'aventure.
Elwin quitte l'aventure.
Indices
  • Le paladin hérite de l'attaque du guerrier, rage comprise : vous n'avez rien à écrire pour cela.
  • Le soin passe par la méthode publique heal() de l'allié, écrite à l'étape 1.
  • Si Warrior et Spellcaster avaient toutes les deux une méthode display(), l'appel serait ambigu. Ici, Spellcaster a displayMana() : pas de conflit.
Pour valider, assurez-vous que…
  • le programme d'essai affiche exactement les lignes attendues ;
  • aucune ligne de Warrior ni de Spellcaster n'est recopiée dans Paladin ;
  • vous avez fait un commit « Classe Paladin » et vous l'avez poussé.

6 L'entraînement et le duel

Synthèse

Le nouveau main.cpp enchaîne une démonstration des trois classes, puis le duel du TP1.

  1. Ajoutez au-dessus de main cette fonction d'entraînement, et incluez Warrior.hpp, Mage.hpp et Paladin.hpp : 
    
          // Démonstration des capacités de chaque classe de héros.
          void training() {
              cout << "=== Les Chroniques d'Ardelune : l'entraînement ===" << endl;
              Warrior brom("Brom", Weapon("Hache de guerre", 15));
              Mage aria("Aria", Weapon("Bâton runique", 6));
              Paladin elwin("Elwin", Weapon("Marteau sacré", 10));
              brom.display();
              aria.display();
              elwin.display();

              cout << endl << "--- Les sorts d'Aria ---" << endl;
              for (int i = 0; i < 4; i++) {
                  aria.castFireball(brom);
              }

              cout << endl << "--- La rage de Brom ---" << endl;
              brom.display();
              brom.attack(aria);

              cout << endl << "--- La bénédiction d'Elwin ---" << endl;
              for (int i = 0; i < 3; i++) {
                  elwin.bless(brom);
              }
              elwin.display();
              cout << endl;
          }
  2. Remettez les fonctions readChoice() et playTurn(Hero& active, Hero& opponent) de votre duel du TP1, sans les modifier.
  3. Dans main, appelez training(), puis faites s'affronter Brom (Warrior, « Hache de guerre », 15 dégâts) et Aria (Mage, « Bâton runique », 6 dégâts). Juste avant le duel, Brom arrive blessé : brom.takeDamage(70);.
