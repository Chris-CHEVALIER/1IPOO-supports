Installer son environnement C++

1IPOO – Initiation à la programmation orientée objet · À faire avant le mardi 1er décembre

Le module 1IPOO se fait en C++. Pour programmer dès la première heure de cours, votre ordinateur a besoin de trois outils. Vous connaissez déjà le premier.

OutilRôle
VS Codel'éditeur où vous écrivez le code (déjà utilisé en Python)
Un compilateur C++ (g++)le programme qui traduit votre code C++ en un programme que l'ordinateur sait exécuter

En Python, un interpréteur lisait votre fichier et l'exécutait ligne après ligne. En C++, un compilateur traduit d'abord tout le fichier en langage machine, puis vous lancez le programme obtenu. C'est pour cela qu'il faut installer un compilateur.

En bref
  • Suivez uniquement la partie de votre système (Windows, macOS ou Linux), puis la partie « Tester ».
  • Comptez entre 15 et 30 minutes, surtout à cause des téléchargements.
  • Si quelque chose bloque, notez le message d'erreur exact et écrivez-moi : nous réglerons le problème au début du premier cours.

W Windows : installer g++ avec MSYS2

Windows 10 ou 11

MSYS2 est un ensemble d'outils libres qui apporte le compilateur g++ sous Windows. Cette procédure suit la documentation officielle de VS Code.

  1. Sur msys2.org, téléchargez l'installateur (msys2-x86_64-….exe) et lancez-le. Gardez le dossier proposé, C:\msys64, puis cliquez sur Next jusqu'à Finish.
  2. Une fenêtre noire s'ouvre : c'est le terminal MSYS2 UCRT64. Collez-y la commande suivante (clic droit → Paste), puis appuyez sur Entrée : 
    pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain
  3. Le terminal demande quels paquets installer : appuyez sur Entrée pour tout accepter. Il demande ensuite Proceed with installation? [Y/n] : tapez Y puis Entrée. Attendez la fin de l'installation, puis fermez le terminal.
  4. Ajoutez le compilateur au PATH, la liste des dossiers où Windows cherche les programmes :
    • dans la barre de recherche de Windows, tapez variables d'environnement et ouvrez Modifier les variables d'environnement pour votre compte ;
    • dans la liste du haut, sélectionnez Path, puis cliquez sur Modifier… ;
    • cliquez sur Nouveau, collez C:\msys64\ucrt64\bin et validez avec OK dans les deux fenêtres.
  5. Ouvrez un nouveau terminal PowerShell (menu Démarrer → PowerShell) et vérifiez que le compilateur répond : 
    > g++ --version
g++.exe (Rev…, Built by MSYS2 project) 15.…

Si PowerShell répond g++ n'est pas reconnu…, le PATH est mal réglé : vérifiez le chemin collé, puis fermez et rouvrez PowerShell (et VS Code). Le numéro de version peut être différent : c'est normal.

M macOS : installer les outils de développement

macOS

Apple fournit gratuitement un compilateur C++ (Clang) avec ses outils en ligne de commande. Vous n'avez pas besoin d'installer Xcode en entier.

  1. Ouvrez l'application Terminal (Spotlight : ⌘ + Espace, puis tapez « Terminal »).
  2. Collez la commande suivante puis appuyez sur Entrée : 
    xcode-select --install
  3. Une fenêtre s'ouvre : cliquez sur Installer, acceptez la licence et attendez la fin du téléchargement. Si le terminal répond command line tools are already installed, les outils sont déjà là : passez à l'étape suivante.
  4. Vérifiez que le compilateur répond : 
    $ g++ --version
Apple clang version 17.…

Sous macOS, la commande g++ lance en réalité Clang, le compilateur d'Apple. Les deux comprennent le même C++ : tout le module fonctionne à l'identique.

L Linux : installer build-essential

Ubuntu, Debian et dérivées

Dans un terminal, installez le paquet qui regroupe g++ et ses outils, puis vérifiez la version :

$ sudo apt update
$ sudo apt install build-essential
$ g++ --version

Sur Fedora : sudo dnf install gcc-c++.

V VS Code : l'extension C/C++

Tous les systèmes
  1. Si besoin, installez VS Code.
  2. Ouvrez l'onglet Extensions (Ctrl + Maj + X, ou ⌘ + Maj + X sur Mac), cherchez C/C++ et installez l'extension C/C++ de Microsoft.
  3. Fermez et rouvrez VS Code.

Une fois l'extension installée, Maj + Alt + F (Maj + Option + F sur Mac) remet votre code en forme automatiquement. Inutile d'installer l'extension « Code Runner » : nous compilerons dans le terminal, ce qui marche aussi avec plusieurs fichiers.

✓ Tester : votre premier programme C++

Tous les systèmes
  1. Créez un dossier cpp-test (sur le bureau, par exemple) et ouvrez-le dans VS Code (Fichier → Ouvrir le dossier…).
  2. Créez le fichier hello.cpp et copiez-y ce programme : 
    
          #include <iostream>

          int main() {
              std::cout << "Bonjour depuis le C++ !" << std::endl;
              return 0;
          }
  3. Ouvrez le terminal intégré de VS Code (Terminal → Nouveau terminal), puis compilez et exécutez le programme : 
    $ g++ -std=c++17 hello.cpp -o hello
$ ./hello
Bonjour depuis le C++ !

La première commande demande à g++ de traduire hello.cpp en un programme nommé hello (hello.exe sous Windows). La seconde lance ce programme. Si le message s'affiche, votre environnement est prêt. 🎉

-std=c++17 choisit la version du langage, la norme C++ de 2017, bien prise en charge par tous les compilateurs récents. -o hello donne le nom du programme produit (output).

G GitHub : vérifier son compte

Déjà fait en 1GEST

Votre projet sera rendu sur GitHub, comme en 1GEST. Vérifiez que :

  • vous pouvez vous connecter à votre compte GitHub et que la double authentification est activée ;
  • GitHub Desktop est installé et connecté à ce compte (File → Options → Accounts sous Windows, GitHub Desktop → Settings → Accounts sur Mac).

GitHub appartient à Microsoft et relève du droit américain (Cloud Act). Je l'utilise parce que je le maîtrise. Des alternatives ouvertes existent, comme GitLab ou Codeberg.

✓ Avant le premier cours

Pour valider, assurez-vous que…
  • g++ --version affiche une version dans le terminal de VS Code ;
  • hello.cpp se compile sans erreur et affiche Bonjour depuis le C++ ! ;
  • l'extension C/C++ est installée dans VS Code ;
  • GitHub Desktop est connecté à votre compte GitHub.

En dernier recours, si l'installation est impossible sur votre ordinateur le jour du cours, un compilateur en ligne comme OnlineGDB permet de commencer en attendant. Votre code est alors envoyé sur un service tiers : n'y mettez aucune information personnelle.
